# 2 分 30 秒评委演示脚本

> 录制目标：1080p、16:9、总时长 2:15–2:45。鼠标移动要慢，画面只保留浏览器，不展示终端中的 API Key。

## 0:00–0:15｜开场钩子

**画面：**首页 Hero，鼠标指向 `Narrative Spread 63 PTS`。

**旁白：**“价格有价差，真相也有。同一条消息，在中文群聊里可能被大量相信，但在英文官方信源中几乎没有支持。我们做的不是另一个聊天机器人，而是跨语言真相套利终端。”

## 0:15–0:35｜社会问题

**画面：**点击第一个预置案例，展示原始转发文本。

**旁白：**“这条消息说，灾民必须先支付 50 USDT，才能领取 2,000 美元救助。它利用紧迫感、善意和语言壁垒传播。传统核查只给结论，却无法解释为什么不同语言的信息世界差这么大。”

## 0:35–1:05｜Gonka 核验路径

**画面：**点击 **运行真相套利**。等待过程可以剪掉，只保留 1–2 秒加载状态。随后指向四步核验路径。

**双模型成功时旁白：**“所有 AI 推理都通过 Gonka Router 完成。第一个模型拆解声明并调查多语言证据，第二个模型作为独立质疑者，专门寻找循环引用、时间冲突、翻译偏差和缺失的一手信源。”

**单模型降级时旁白：**“所有 AI 推理都通过 Gonka Router 完成。这个 Key 当前只路由到 MiniMax，所以系统没有伪造双模型共识，而是在失败后有限回退，并把本次结果明确标记为单模型降级。”

## 1:05–1:30｜结果揭晓

**画面：**依次指向 Truth Score、结论、Narrative Spread 和原子声明。

**旁白：**“结论是 9 分，严重失实。但真正的产品洞察在这里：中文信息圈的叙事支持度比英文信源高 63 点。大量转发看似是很多证据，其实可能都来自同一张匿名截图。”

## 1:30–1:50｜证据与行动

**画面：**展开一条证据，然后展示安全行动卡片和评分权重。

**旁白：**“我们不只说真假，还告诉用户下一步怎么做：不要付款、保留钱包地址、联系官方机构。分数由公开权重编译，传播热度不会被当成真相，也不由第三个模型拍脑袋。”

## 1:50–2:15｜Sponsor 技术证明

**画面：**滚动到审计账本，放大一个真实 Gonka Request ID、实际模型、延迟和 Token 用量。若当前是预置结果，必须先切换到一次 live run，不能把 `simulated-not-network-proof` 当作真实凭证。

**旁白：**“每一次声明提取、调查和质疑，都记录真实 Gonka Request ID、模型、延迟、Token 和输入摘要。任何人都可以审计，是哪个模型、在哪一步做出了判断。Gonka 不是隐藏的 API，而是这个产品的信任层。”

## 2:15–2:30｜收尾

**画面：**回到总结果，停在 Logo 与一句话定位。

**旁白：**“Truth Arbitrage，让真相摆脱单一语言、单一平台和单一模型。我们希望把它变成每个人都能使用的公共 AI 核验基础设施。”

## 录制前准备

1. 运行 `npm test` 和 `npm run build`。
2. 运行 `npm run smoke:gonka`，确认录制时实际可用模型。
3. 关闭通知、书签栏、密码管理器弹窗和其他浏览器标签。
4. 浏览器缩放设为 90% 或 100%，确保结果和审计账本清晰可见。
5. 使用一个不含隐私、可公开核查的 live 输入，提前跑一遍估算等待时间。
6. API Key 只放在服务器 `.env`；视频中不展示环境文件或终端历史。

## 推荐剪辑结构

- 加速或剪去 Gonka 网络等待，不剪改结果本身。
- 关键数字只加三处字幕：`Truth Score`、`Narrative Spread`、`Gonka Request ID`。
- 使用轻量背景音乐，旁白优先；不要让特效抢走审计信息。
- 结尾保留 3 秒项目名、Demo URL、GitHub URL 和二维码。

## 评委追问备用演示

- 评委问“是否只会判假”：点击应急饮水站正向对照案例，结果为 **VERIFIED**。
- 评委问“能否处理复杂表述”：点击电动车全生命周期排放案例，结果为 **MISLEADING**，而非简单 FALSE。
- 评委问“证据是否只是模型知识”：展开证据行，展示来源、时间、语言、立场与可靠性。
- 评委问“是否真的接入 Gonka”：展示 **LIVE ON GONKA** 与真实 Request ID；预置案例只用于稳定叙事演示。

## 录制失败时的底线

- Kimi 不可用：展示并解释单模型降级，不要口播“双模型已达成共识”。
- Gonka 限流：等 `Retry-After` 后重录 live 片段，不在视频中长时间等待。
- 开放检索暂时失败：可以使用预置案例讲产品，但 Sponsor 证明片段必须来自一次真实 Gonka 调用。
